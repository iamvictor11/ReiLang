# ReiLang
名为 Rei 的可嵌入式脚本语言。
## 简介
Rei 是将要用于编程音乐的脚本语言。目前仅支持播放midi音符，后续会引入合成器(可能会很久很久以后:<)。
## 语法、特性
### 类型
- 类型有 nil，bool，int，float，string，array，func，native；
- string，array，func，native 为引用类型；
- bool 可以用 true false 表示；
- int 可以用 二进制，八进制，十六进制 表示；
- float 可以用 科学计数法 表示；
- int 和 float 可以用 ' 分割，不影响结果；
### 运算符
- 有多种运算符，详见 script/expr.rei ；
- := 可以省略 var 关键字来定义变量；
- $= 为克隆赋值符号，$:= 为克隆定义符号；
- 支持自运算赋值符号：+=，-=，*=，/=，%=，**=，&= 等等；
- 所有赋值和定义符号都可以链式传递；
- 所有类型都可以相互运算，会根据不同的组合结果不同；
- 支持 () 控制优先级，[] 作为 array 的初始化表达式，{} 作为语句块限制变量的声明周期和作用域；
- {} 语句块会上层被视为单个语句；
- string 可以用 "" 或 '' 初始化；
- string 支持用 \ 作为转义字符；
- func 使用 () 调用；
- func 在调用时可以不用对齐参数数量；
- array 使用 [] 索引；
### 关键字
- // 为单行注释；
- \ 在 string 字面量外会被忽略；
- 可以使用 var 关键字来定义变量，func 定义函数；
- if elif else 作为条件语句关键字，使用 then end 包含代码，如果是单个语句可以省略包含块；
- if 有别名为 when；
- while until continue break 作为循环语句关键字，使用 do end 包含代码，如果是单个语句可以省略包含块；
- while 有别名为 loop；
- until 是条件为假时执行循环；
- continue break 可以在后面加编译器字面量来控制层数；
- func 仅可以在全局作用域中定义，()包含参数，once 后接该函数的持久变量，beg end 包含函数，如果是单个语句可以省略包含块；
- return 用来返回函数，默认返回 nil，即使函数没有return，return: 后接指定返回的值；
### midi
- bpm 用来设置全局的 bpm，默认 120 ；
- beat 用来设置全局的一拍为几分音符，默认 1 ，例如 beat 2 就是一拍为二分音符；
- channel 用来设置当前全局使用哪个管道，默认 1 ，范围 [1, 16]；
- program 用来设置当前全局管道使用什么乐器，默认 0 ，范围是 midi 的规定，可以用字符串匹配；
- volume 用来设置当前全局管道的音量，默认 0x7F ，范围 [0x00, 0x7F]；
- velocity 用来设置全局音符播放时的力度，默认 0x7F, 范围 [0x00, 0x7F]；
- play 用来播放音符，范围是 midi 的规定；
- unplay 用来关闭音符，范围是 midi 的规定；
- wait 后接等待的拍数，目前用 std::this_thread::sleep_until() 实现，后续可能会优化；
## 构建和运行
- 使用 GCC + CMake；
- 目前仅仅支持 windows 平台；
- build_release.bat 可以在 windows 直接生成发布版本；
## 常见问题解答
### 设计的原因是什么？
我本来想找个编码写音乐的脚本语言，但是大多都是不可嵌入的，且协议很严格，所以就自己心血来潮做了这个项目，但是精力有限，内容太少了，以后会不会更新，难说。
### 未来展望
- 合成器功能；
- 异步函数；
### 可以使用 Rei 到自己的项目吗？
本项目是开源的，代码可以用作于他人项目中。它采用 MIT 许可证，很宽松，但必须注明出处。
